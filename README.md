# MCU：单片机原理实验答案

基于 AT89C51 的 8 个单片机实验示例，包含简单直白的 C51 源码、Keil uVision 工程和 Proteus 仿真文件。

## 实验内容

1. LED 流水灯
2. 数码管轮流显示数字
3. 四位数码管动态显示
4. 独立按键控制 LED
5. 矩阵键盘控制 LED
6. LCD1602 字符显示
7. 外部中断控制 LED
8. 定时器中断控制 LED

## 使用方法

- 使用 Keil uVision 打开各实验目录中的 `.uvproj` 工程并编译。
- 使用 Proteus 打开 `.pdsprj` 工程；如提示缺少程序文件，请先在 Keil 中编译，再在单片机属性中选择生成的 HEX 文件。
- 编译产物和个人本机配置未纳入仓库，需要在本机重新生成。

代码仅用于学习交流，建议理解实验原理后自行完成实验。
